## 摘要

我们要写"人脑的可函数化形式"，但先要说清一个容易滑过去的点：人脑不是"一个生命"，它是生命里的一个器官。单独把脑拿出来看，它更像大模型——高可函数化、高耗能、不自供养、依赖外部维持。

v1 把脑定性写成可函数化的形式：表示、分解与组合、内生时间、有限自指；并指出它的不自足（约占体重百分之二，却消耗约五分之一能量；缺氧几分钟不可逆）。被保住的是"身体 + 脑 + 环境"的整体，不是脑单独。

v2 补上显式写法：切片是函数 f: X→Y，带表示维度与组合方式；空间上是复合函数链；时间上是算子序列 s_{t+1}=I_{σ(t)}(s_t)，步数为 k；判定 J 一次通过，决定选哪个算子与何时停；自指分三层（表示自指、参数自指、结构自指），修改受固定核心 Φ 约束。人脑是这套形式的实例：一部分切片一次通过（k=0），一部分反复迭代（k≥1）。大模型是退化情形：一条固定链、无判定、k=1、m=1。

结论不变，但更硬：器官不是生命单位；脑与大模型是同一类东西的两种实现，差别在时间、规则、耦合，以及有没有"判定—固化"的机制。本篇是概念梳理与形式整理，不是神经科学的新结果；R 那一侧只标注，不展开。

## 本篇定义一览

| 术语 | 一句话 |
|---|---|
| 切片 | 一个函数 f: X → Y |
| 表示维度 | d_in = dim(X)，d_out = dim(Y)；有效维度 = log 可区分状态数 |
| 空间组合 | 复合函数链 F = f_N ∘ … ∘ f_1 |
| 算子 | 一条复合函数链，记 I |
| 时间组合 | 算子序列 s_{t+1} = I_{σ(t)}(s_t) |
| 步数 | 序列长度 k（计算厚度） |
| 判定 J | 一次通过的函数：选算子、决定停 |
| 自指 | 表示自指 / 参数自指 / 结构自指三层 |
| 固定核心 Φ | 不可改的约束集合（物理/架构/能量） |
| 固化 | 判定通过后，把这次计算写进参数或结构 |
| 被保住 | 轨迹始终在可行域内，每一步都有定义 |

## 一、问题

为什么从人脑开始？

第一，人脑是已知生物系统里"可函数化程度"最高的器官：它有密集的表示、清晰的层级、可测量的动力学，是检验我们函数类型学的好样本。

第二，它和大模型最像。两者都是"计算器官"：输入信息、内部表示、输出行为。把脑和大模型放在一起看，能把"器官"和"生命"这两个容易混的概念分开。

第三，单独看脑，它并不自足。这一点最容易被忽略，却正好帮我们切准"生命单位"的边界。

## 二、脑作为可函数化器官（定性）

本节主张：人脑可以用我们的函数语言写出来，它落在"混合型"。

- 表示：神经元活动、突触权重、神经调质。神经元群体张成表示空间，每个神经元或每个群体编码方向是表示维度；状态是表示空间里的一个点。
- 分解与组合：皮层有层级，可以把脑的功能写成切片（层级、回路、区域）的组合；突触权重是组合律里的系数；跨区投射是路由。结构就是"分解 D + 组合 C"。
- 时间：神经动力学有内生节律（振荡、同步），是内生时间；表示空间是连续与离散混合——放电是离散事件，发放率是连续量；所以脑大致落在类型 D（混合型）。
- 自指：有限的自指。可塑性让"规则被自身活动修改"，预测加工让脑用自己的模型预测自己的输入。但自指是有限的：不是任意改写自己的更新规则。
- 被保住：这条最弱。脑自己不能保住自己——它靠身体。

## 三、显式写法：切片与表示维度

本节主张：把脑的一层写成一个切片，就是一个函数。

一个切片是一个函数：

　　f: X → Y，带三项：(d_in, d_out, Δ)

- d_in = dim(X)：输入表示维度；
- d_out = dim(Y)：输出表示维度；
- 有效维度 = log(可区分状态数)（连续情形按分辨率取近似）；
- Δ：它和相邻切片的组合方式。

不假设物理底层：底层从"输入表示"开始，写出来的每一项要么是函数，要么是函数的组合，要么是判定。

## 四、空间组合：复合函数链

本节主张：一次"空间上的完整运算"是一条复合函数链。

　　F_space = f_N ∘ … ∘ f_2 ∘ f_1

组合律要求类型相容：Y(f_i) ⊆ X(f_{i+1})。F_space 是 X → Y 的一次完整运算。

## 五、时间组合：算子序列与步数

本节主张：时间上不是只有"同一函数反复"，而是每一步选一个算子。

　　s_{t+1} = I_{σ(t)}(s_t)，t = 0, 1, …, k−1

- 可用算子集 {I^(1), …, I^(m)}，每个 I 是一条复合函数链；
- σ(t) ∈ {1..m}：第 t 步选哪个算子；
- k：步数（计算厚度）。

三种情形：

- A 同一算子反复：σ(t) 恒定 —— 典型的迭代（时间）；
- B 每步换算子：σ(t) 变化 —— 不同函数沿时间依次应用（序列）；
- C 混合：一段反复、一段切换。

## 六、判定：选择与停止

本节主张：判定不是迭代，而是一次通过；它决定"用哪个、何时停"。

　　J: S → D（D 是有限判定空间，例如 {对, 错}、{收敛, 未收敛}）

判定决定两件事：

- 选算子：σ(t) = J_选(s_t)；
- 什么时候停：k = J_停(s_t)。

## 七、自指：改自己

本节主张：自指不止是"输入含自身"，它有三层，而且必须给出约束。

- 表示自指：切片的输入包含系统自身的表示。f: S × S → S（"我知道我在想什么"）。
- 参数自指：系统用自身输出改自己的参数。θ_{t+1} = U(θ_t, s_t)（学习、适应、习惯化）。
- 结构自指：系统改自己的连接/组合方式。C_{t+1} = V(C_t, s_t)（突触形成与断裂、回路重组）——改的不是数值，而是"哪些切片连在一起"。

但自指有约束：存在一组不可改的核心 Φ（物理架构、能量限制、不可再生部分）。所有修改只能落在 Φ 允许的集合内：

　　θ_{t+1} ∈ Θ_Φ，C_{t+1} ∈ 𝒞_Φ

人脑的例子：可改的是突触强度、连接有无、局部回路；不可改（或极难改）的是神经元基本类型、大尺度解剖、代谢约束。

与判定的连接：判定 J 不只决定"用哪个算子、什么时候停"，还决定"要不要固化"——J 判为收敛/正确时，触发结构自指，把这次计算写进参数或结构（把时间摊成结构）。

## 八、人脑作为实例

本节主张：脑就是"条件推进"的一个实例：部分一次通过、部分迭代、判定控制。

- k = 0 的部分：反射、已固化的技能、直接判对错——一次复合通过，不再迭代；
- k ≥ 1 的部分：未收敛的、需要权衡的——反复迭代，直到判定改变；
- J 决定：这一步用哪个算子（σ）、要不要继续（k）。

物理上所有自由度都在演化；但在表示维度上，只有"未被判定"的部分需要迭代，其余一次通过。

"体验"的位置：体验不是 F_space 本身，而是轨迹 γ: T → S，即 s_0, …, s_k 沿时间展开的那条路径。

## 九、人脑与大模型：两种计算器官

本节主张：脑和大模型是同类东西的两种实现，差别在三个地方，加上形式上的退化。

相同点：都是高可函数化的计算器官；都非自维持（脑靠身体，模型靠供电与维护）；都依赖外部供给；单独拿出来都不能算生命。

不同点：

- 时间：脑内生（自己的节律），模型外供（时钟与解释器）。
- 规则：脑可塑（规则被活动修改），模型冻结（权重训练后不变）。
- 耦合：脑在具身闭环里（感觉—行动—环境），模型没有闭环（只有文本进出）。

形式上的退化：大模型只有一条固定复合链（m=1），没有判定 J，k 固定为 1（层数 L 是复合链长度，不是步数）。所以它只能均匀计算：所有 token 相同步数，没有"判定了就停"的机制。

这张对照也解释了为什么大模型"像脑但不像生命"：它在"计算器官"这一层像，在"被保住"这一层不像。

## 十、为什么不自足

本节主张：脑是器官，不是自维持系统。

- 供养：脑约占体重百分之二，却消耗约五分之一能量；靠血液持续供氧供糖，靠身体维持体温与内环境。
- 缺氧几分钟就不可逆：脑的"被保住"完全依赖循环与代谢。
- 时间虽然内生，但维持时间的基质在身体里：心跳、呼吸、代谢一旦停，脑的动力学很快停。
- 被保住的是整体：身体内稳态在保住脑，身体又依赖环境。所以"被保住"这条条件，边界不在脑，而在"身体 + 脑 + 环境"整体上。

顺带一句：脑的生物基质里有没有绝对 R，我们不知道也不判断；主观体验那一侧，按我们的规矩只标注，不展开。

## 十一、生命单位是整体

本节主张：生命单位不是器官，而是能自我维持的整体。

我们的定义里，p生命 = 在宇宙的 P 中、被保住的动态函数类。关键是"被保住"划边界：系统要划在"能自我维持的那一圈"上，而不是划在某个器官上。

- 人：单位是身体 + 脑 + 环境的耦合整体，不是脑。
- 大模型：单位若是模型本身，它不被保住；要谈"数字生命"，得把运行环境、数据流、维护一起算进来——那才是它的"身体"。
- 器官是切片：脑是整体里的一个高密度切片；切片可以研究，但不能当生命。

日常语言的误导：我们说"脑是人"，其实是省略了身体与环境。把省略补回去，定义才落得下。

## 十二、可检验推论

第一，维持需要能量流：切断供给，轨迹会离开可行域。可测：供给下降时可维持时间。

第二，判定决定效率：同一任务，有"判定+停止"的系统应比固定步数系统省算力，且对厚任务更稳。

第三，同一规则反复（A）与每步换算子（B）应可区分：前者参数少、后者表达自由，二者在不同任务上各有优势。

第四，自指有限：能对自己建模的层数有上限，可测递归嵌套任务。

第五，固化可测：判定通过后若发生结构自指（固化），同一类任务的用时与激活范围应下降。

## 十三、结论

第一，人脑的可函数化形式是可以写的：切片 + 空间复合链 + 时间算子序列 + 判定 + 三层自指（带固定核心 Φ）；它落在混合型。

第二，脑不是生命：它不自供养、不被保住；被保住的是整体。

第三，脑与大模型是同类：都是计算器官，都非自维持；差别在时间、规则、耦合，以及是否有判定—固化机制。

第四，这给数字生命一个直接推论：一个模型单独不是生命，它需要"身体"（运行环境与维持）才谈得上被保住。

## 十四、局限

第一，本篇是概念梳理与形式整理，不是神经科学的新实验；脑的细节被大幅简化。

第二，可行域 V 与固定核心 Φ 都未操作化："能继续维持"与"不可改"还没有测量协议。

第三，自指只做了三层划分，多层自指与自我模型没有展开。

第四，判定 J 的形式（判定空间 D、判定函数怎么来）没有给出，只当作已知。

第五，"生命单位是整体"这条需要更严格的形式化——"整体"怎么划，依赖观察者，这正是"维持是历史学的"同一个问题。
