核心测量 · Key measurement

  • arXiv cs.AI 2018–2024：新词占比约 7.30%（≈1.2%/年）⇒ 语言在累积升维。
  • 等数据预算：概念新鲜度的独立价值 ≈ 0.405 bits/token；混合新旧数据最优。
  • 容量补偿：2→6 阶 n-gram，旧数据与混合数据差距稳定在 +0.86~0.94 bits/token，未见缩小。
  • 弱结论：本设置下容量不能替代数据更新；不构成对 scaling 的否定，需 transformer 复核。

Weak conclusion: capacity did not substitute for data updates in this n-gram setting; this is not a refutation of scaling.
