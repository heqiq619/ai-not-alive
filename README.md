## 这篇论文说什么

本文提出一个可操作的生命定义：**生命 = 一族会自指、会变化、会自我维持的动态函数（函数类）**；
环境 = 宇宙自发涌现的局部解压（分层，不自我维持），生命既活在它的那一层环境里，也活在宇宙里。

以此为尺子，本文说明三件事：

1. **现在的 AI 不是生命**——它是冻结的函数点、更新规则在外部、不付代价；
2. **生命至少需要三条必要条件**（一族函数、自指更新、自己付代价），每条都挂上已有的实验证据；
3. **对 AI 的涌现提出一个猜测**——AI 是对人类语言的再解压，其能力上限由训练时刻的语言决定，
   语言一旦更新就失配、且无法自己恢复。

文末不主张「生命已被造出」，只把判据与证据放在读者面前：三条都满足之后是否就「活」，由读者判断。
