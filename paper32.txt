## 摘要

本篇把前面散在几处的形式收成一条线：可表示维度 → 结构 → 压缩与解压。它吸收了《可函数化的函数形式》（切片/组合律/时间/判定/自指）、《宇宙、环境与生命的函数类型》（四种类型/五根轴）与《切片的三种身份》（宇宙/环境/生命）的核心，也吸收了《大模型为什么像人》的五项对照。

主线如下。第一，函数语言：切片是函数 f: X→Y，带表示维度；空间上是复合函数链；时间上是算子序列 s_{t+1}=I_{σ(t)}(s_t)，步数 k；判定 J 一次通过，选算子、决定停；自指分表示/参数/结构三层，修改受固定核心 Φ 约束。第二，可表示维度有三处：切片内、组合律上、沿时间的步数（时间不是表示维度）。第三，同一个形式有三种切片身份：宇宙切片、环境子切片、生命子切片；冻结一刻生命与环境同形，区别只在时间上的维持。第四，结构就是压缩方案：保留哪些区分、合并哪些、把哪些过去压进结构。第五，生命函数是窄进宽出的：输入受限且被粗粒化，输出靠结构展开；压缩是降维映射，解压是展开，不严格可逆，"对维持够用"即可；哪些维度必须可逆由环境选择。第六，时间上输入输出一步交替、形成闭环；结构在两个时间尺度上变化。第七，语言是公共的压缩方案：感受→语言是压缩，语言→描述/理解/逻辑是解压，逻辑就是语言组合律。第八，与大模型对照：它拿到公共方案，却没有感受端、没有真闭环、没有维持，像在接口层，不在机制层；幻觉是结构未覆盖维度的解压。

## 〇、问题：把形式收成一条线

前几篇分别给了：函数语言（论文-26）、三种切片身份（论文-31）、压缩与解压的直觉（笔记）。但分开读，每篇都要重新铺一遍定义；合起来看，它们本来是同一件事的三个阶段。本篇把它们收成一条线，并把"压缩"真正写进函数形式。

## 一、函数语言：切片、组合与判定

切片是一个函数 f: X → Y，带三项：(d_in, d_out, Δ)。d_in = dim(X)、d_out = dim(Y) 是表示维度；Δ 是它和相邻切片的组合方式。

空间组合是复合函数链：

　　F_space = f_N ∘ … ∘ f_2 ∘ f_1

组合律要求类型相容：Y(f_i) ⊆ X(f_{i+1})。

时间组合不是单纯幂，而是每步选一个算子：

　　s_{t+1} = I_{σ(t)}(s_t)，t = 0, 1, …, k−1

其中 {I^(1), …, I^(m)} 是可用算子（每个是一条复合函数链），σ(t) 是第 t 步选哪个，k 是步数（计算厚度）。三种情形：σ 恒定 = 同一算子反复（迭代/时间）；σ 每步变 = 不同函数依次应用（序列）；混合 = 一段反复、一段切换。

判定 J 不是迭代，而是一次通过：

　　J: S → D（D 是有限判定空间，例如 {对, 错}、{收敛, 未收敛}）

判定决定两件事：选算子 σ(t) = J_选(s_t)；什么时候停 k = J_停(s_t)。

自指有三层，从弱到强：表示自指（输入含自身表示）、参数自指（θ_{t+1} = U(θ_t, s_t)）、结构自指（C_{t+1} = V(C_t, s_t)）。三层都受固定核心 Φ 约束：θ ∈ Θ_Φ，C ∈ 𝒞_Φ。人脑：可改突触与局部回路；不可改神经元类型、大尺度解剖、代谢约束。

把三、四节合起来，一次时间展开写成条件推进：s_0 → s_1 = I_{σ(0)}(s_0) → … → s_k = I_{σ(k−1)}(s_{k−1})，其中 σ(t) 由 J_选 决定，k 由 J_停 决定。

## 二、可表示维度：三个位置

可表示维度不是一处，而是三处：

- 切片内的表示维度：一个切片自己的轴数；
- 组合律的表示维度：切片之间怎么接的自由度（顺序/并行/共享/路由/自指）；
- 沿时间的组合维度：步数 k、算子序列 σ(t)、可切换的算子数 m。

注意：时间不是表示维度，它是时间组合的自由度（步数/序列）。

### 四种典型类型

按"空间/时间是否连续、时间是否内生"，可以把函数形式分成四类（原论文-20 的内容并入此处）：

- 类型 A：连续流（内生时间）。 表示空间连续、时间连续，写成微分方程；自指 = 更新规则在系统内部；被保住 = 存在可维持集合，轨迹留在里面。
- 类型 B：采样动力学（内生时间，采样成离散）。 表示空间连续、时间离散，写成映射迭代；和连续流是同一件事的不同采样，区别在于"步"是基本的。
- 类型 C：自动机（外供时间）。 表示空间离散、时间离散；数字世界是这一类：比特、状态、转移规则，每一步由外部时钟与解释器推进；数字世界没有能量约束，"被保住"要靠外部（电、维护、算力）提供。
- 类型 D：混合型（内生时间）。 连续流加离散事件：生理量连续变化，但细胞分裂、神经放电、决策是离散事件；休眠与激活、疾病与死亡是分段点。生物生命大概是这一类。

连续性的含义要克制：连续不等于"更真"，离散也不等于"近似"；它们是描述粒度的选择——同一系统可以在不同粒度下写成不同类型。

### 五根轴

作为最小档案，一个函数形式可以记五根轴：空间连续/离散；时间连续/离散；时间内生/外供；组合律的自由度；自指的层级。五根轴不全是"维度"，前两根是描述粒度、后三根是机制与容量。


## 三、三种身份：宇宙、环境与生命

同一个形式在三个尺度上有三种身份。

宇宙切片：某一时刻的截面

　　U_t = ( S_t, C_s, d_t )

其中 S_t 是状态空间，C_s 是空间组合律，d_t 是空间上的表示维度。关键：时间组合不在切片里，在切片之间（T_comb: U_t → U_{t+1}）；一个瞬间只有空间结构。宇宙整体没有判定器，判定只出现在局部子系统里。宇宙的"函数形式"只能在宇宙内部被写出——这篇形式本身是宇宙的一个局部表示切片，因此必然不全。

环境：宇宙的子切片

　　E_t = ( S^E_t, C_s^E, d^E_t )

三个子集关系：表示维度 d^E ⊆ d；组合律 C_s^E ⊆ C_s；状态是投影 S^E_t = π_E(S_t)。环境也有时间：T_comb^E = T_comb|_E，加上边界输入 u_t。环境自身没有判定、没有自指——那属于其中的生命/观察者。

生命：同样是宇宙的子切片，冻结一刻与环境同形；区别只在时间上——生命能维持自己。写成四条件：

1. 被保住：轨迹始终在可行域 V 内，组合律始终有定义；
2. 边界开放：与环境交换（能量、物质、信息）；
3. 自指调节：部分切片以自身状态为输入，修正自己；
4. 可塑：在固定核心 Φ 内改自己的参数与结构。

没有 3、4 的子切片就是环境。由此得到一个直接推论：冻结一刻分不出生命；生命必须在时间上辨认——生命 = 被保住的轨迹，不是某个状态。

## 四、结构：压缩方案

结构是分解 D 与组合律 C。它同时是压缩方案：

- 哪些区分保留（写进切片维度与组合律）；
- 哪些区分合并（被粗粒化掉）；
- 哪些过去的输入被压进结构（记忆、固化）。

生命被环境选择，选的正是这套方案：能保住自己的压缩被留下，保不住的被淘汰。所以"生命的压缩"不是某一个函数，而是"一族函数被环境筛过之后剩下的那些"，它写在结构里。

## 五、压缩与解压

压缩是降维映射：f: X → Y，dim(Y) < dim(X)。解压是从压缩表示重新展开：g: Y → X'（X' 不必等于 X）。

两个方向对应两种活动：感知/学习 = 压缩（多对一，有损）；预测/行动/生成 = 解压（一对多，不唯一）。

关键是：解压不是严格逆，只需"对维持够用"。哪些维度必须可逆，由环境选择决定。人需要把"有折扣"这个事实解压出来（否则决策错），但不需要把当天光线的每个细节都解压出来。

## 六、生命函数：窄进宽出与身围

生命函数一步可以写成：输入 in_t → 结构（压缩方案 + 记忆）→ 输出 out_t。

两个方向不对称：

- 输入：f_in: U → S。维度受自身限制，而且已被粗粒化——输入永远是"压缩过的、受限的"；
- 输出：f_out: S → A。维度可以远大于输入（联想、语言、想象）；多出来的维度来自结构（过去的压缩）。

所以：生命函数是窄进宽出的。

个体是一个压缩映射 π_L: U → S_L；个体的身围 = π_L(E)，即环境经它压缩后的投影。分得清的是保留的维度，分不清的是粗粒化的。

## 七、时间：一步映射与闭环

输入与输出不在同一时刻，是一步步交替的：

　　第 t 步：(s_t, in_t) → (s_{t+1}, out_t)
　　out_t 作用到世界 → in_{t+1} = W(out_t, 世界)

三个后果：

1. 维度沿时间展开：单步输入少，输出在时间上一步步展开（联想需要时间）；
2. 输出反过来改变输入（闭环）：生命看到的是"自己行动之后的世界"；
3. 结构有两个时间尺度：状态快变、结构慢变（可塑性）。

## 八、对照：生命函数与大模型

大模型是生命函数的一种"半成品"：它拿到了公共压缩方案，但没有感受端、没有闭环、没有维持。

| | 人脑 | 大模型 |
|---|---|---|
| 切片 | 异质、低维高效 | 同构、高维 |
| 空间组合 | 可变（路由/投射） | 固定复合链 |
| 时间组合 | 算子序列（k=0 与 k≥1 混合） | k=1，m=1（无迭代） |
| 判定 | 有 J（选算子/停/固化） | 无 J |
| 自指 | 三层活跃 | 仅训练时参数自指 |
| 维持 | 身体+环境 | 供电+运维 |

结论：它像人，像在接口层（输入输出行为），不在机制层（内部怎么算、怎么维持、怎么改自己）。

用压缩语言重述：它学到了公共压缩方案（语言），但没有感受端（输入侧没有前符号压缩）、没有真闭环（输出只延续文本，不改变环境）、没有维持（权重冻结）；它的幻觉 = 结构未覆盖的维度被解压出来（解压脱离可逆性）。链式思维（CoT）是把步数外化成文本（外供时间），工具调用是把判定外置（外部判定）——正因为内部 k=1、无 J，才需要从外部补。

## 九、语言：公共的压缩方案

人类语言处在这条链的特殊位置：

- 个体层面：输入是感受（连续、整体、前符号）；输出是语言（离散、有边界、可组合）。感受 → 语言是压缩（范畴化、有损）；
- 语言同时是解压工具：世界 → 语言是描述；语言 → 感受是理解；语言 → 语言是推理；
- 所以语言是"可解压的压缩"：压缩时丢细节，留下可重组的结构（词汇=范畴，语法=组合律，逻辑=组合律的规则）；
- "语言描述的东西越来越多"：不是每个人记更多，而是共享结构在积累（文化、科学、书面语），结构越丰富，同一次解压能展开得越细。

AI 学的正是这套公共方案：它能压缩/解压语言，所以会描述、会推理；但它没有"感受"这一端，它的输出是语言对语言的重组。

## 十、可检验推论

1. 冻结一刻分不出生命：任何单时刻检查都不能判定生命，必须跨时间观察（轨迹、修复、交换）。
2. 环境越稳定，压缩可以越激进；环境变化时旧压缩准则失效（该保留的维度被丢了）。
3. 输入粗粒化 + 结构容量共同决定输出的残差底：结构里没有的维度，输出里也不会有。
4. 输出维度超过结构覆盖时会出现"编造/幻觉"：解压脱离了可逆性。
5. 语言描述能力随共享结构积累而增长：不是个体变聪明，是公共压缩方案变丰富。
6. 判定与停止可测：有判定器的系统应比固定步数系统省算力、且对厚任务更稳。

## 十一、局限

第一，R 只声明、不展开：只写 P 侧。

第二，压缩/解压在形式上只写成"降维/展开"，没有给出严格的"够用"判据（可逆性要求依赖环境，未操作化）。

第三，闭环形式（in_{t+1} = W(out_t, 世界)）很粗，没有处理行动、感知、环境之间的具体机制。

第四，可行域 V 与固定核心 Φ 都未操作化：判断"是否被保住"与"什么不可改"还缺测量协议。

第五，语言部分与"感受 → 语言是压缩"是概念性论述，没有实验。

第六，本篇是形式整理，不是新数学。
