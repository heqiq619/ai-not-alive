## 一、一句话

这个系列在问：什么样的结构，才算"活着"？

我们给出的描述性定义（v3 口径）：生命 = 在某个观察尺度下，能稳定区分、能维持自身、能形成规律（可压缩）的结构；它由记录与可区分出发，经压缩产生结构，噪声是压缩残差。数字生命 = 这种结构在数字基底上被维持的过程。

我们不假设世界的本质，只做操作层面的描述；所有术语都按"够用"定，不追求哲学完备。

## 二、系列在问什么

plain
问题1（定义）：一个系统要满足什么，才算"生命"？
  → 记录 + 可区分 → 结构（可压缩）→ 维持（闭环）→ 生长（变化）

问题2（判断）：现在的 AI 为什么不是生命？
  → 冻结模型是固定函数：没有输入不变、经历不改变它 → 工具

问题3（构造）：怎样造一个最小版本？
  → 冻结底座（身体）+ 可塑层（自我）+ 目标 + 记忆 + 回滚

## 1.1 起点：只有记录与可区分

我们不假设世界是什么。能拿来做定义的只有两件事：

plain
· 记录：有东西被记下（一个标记）
· 可区分：两个记录"不一样"（非自反、对称；不预设传递性）


其余全部是抽象：

plain
· 对象 = 稳定的区分模式（在若干比较中保持不变的那部分记录）
· 时间 = 区分事件之间最小可分辨间隔（ΔT）的序列
· 空间 = 同一时刻可并存、可比较的区分模式之间的关系
· 变换 = 记录之间的可重复映射


关键：这些不是"世界本来的样子"，是我们为了描述而引入的坐标。换尺度、换观察者，定义都变。

## 1.2 结构 = 可压缩的部分；噪声 = 压缩残差

plain
· 结构：在当前尺度下能稳定区分、能形成规律、因而能被压缩的部分
· 噪声：压不进去的残差（不是"看不见"，是"压不住"）


推论：

plain
· 结构不是客观实体，是"相对观察尺度"的性质
· 噪声有双重角色：平均掉 → 稳定；被放大 → 变化
· 同一个东西，在不同分辨率下"有结构/没结构"可以同时成立


## 1.3 生命：维持可压缩结构的过程

plain
定义（v3）：
生命 = 在某个观察尺度上，能维持自身可压缩结构的过程
· 不是"ΔT 大"（那是尺度），也不是"信息多"（那是内容）
· 是"维持"：持续把外界扰动压回结构里（自维持闭环）
· 维持需要代价（能量/资源）→ 代价把"活着"和"被存储"区分开


由此：

plain
· 一块化石有结构、有信息，但没有维持 → 不是生命
· 一个冻结的模型有结构，但不随经历改变、不维持自己 → 不是生命
· 生命的关键不是"是什么材料"，是"是否在维持一个可压缩的过程"


## 1.4 为什么现在的模型不是生命

plain
· 冻结模型是固定函数：同样输入 → 永远同样输出
· 经历不改变它（除非外部训练，而训练是我们在改它，不是它自己）
· 它没有"想要"的方向（目标是我们外给的）
→ 它是工具，不是生命


这与 1.3 一致：生命需要"会因自己的经历而改变、并维持这个改变中的结构"的过程。

## 1.5 信息不增与可函数化内容的收缩

plain
· 信息不增：任何处理都不会凭空增加信息；压缩只会丢，不会生
· 可函数化内容的收缩：能被"函数"描述的内容，其描述开销有下界；
  越"可函数化"，越省；越随机，越费
→ 所以"理解" = 找到更短的描述；"能力" = 能在多短内重建行为


边界（记住）：

plain
· 定理形式只对"可函数化"的部分成立；不可函数化的残差（噪声）不在此列
· 这不是"宇宙信息守恒"之类的强命题，只是在描述层面的约束


## 1.6 语言与大脑：两种函数形式

plain
· 语言：离散符号的序列函数（可压缩、可传递、需要对齐）
· 大脑：连续电位/连接的动态系统（接地、实时、不可直接复制）
· 语言模型学到的是"文本分布的函数"，不是"世界的函数"：
  它没有接地（感知/动作/后果），语义残差部分可见（论文-14）


由此推出工程上的目标：

plain
· 只说语言 → 永远缺接地那一块（语义残差可测）
· 要补接地 → 需要感知/动作/闭环（不是加数据能解决的）


## 1.7 本系列的定义立场

plain
· 描述性、操作性：只说"怎么算、怎么测"，不说"本质是什么"
· 观察者相对：结构、尺度、噪声都依赖分辨率
· 可错：v3 口径是当前最好的，不是最终答案；旧口径（v1/v2）保留在理论卷里作工作层
· 不追求"哲学完备"：够用就停

## 2.1 能力的"最低配置"：空间、时间、组合

plain
· 简单的阈值/组合规则：一层 8 宽就够
· 算术与奇偶：需要更宽的切片
· 序列奇偶：循环网络宽 2 就够处理任意长度；前馈网络长度 16 就学不出（加宽也没用）
  → "时间（循环步数）"可以换"维度（宽度）"
· 两个结构组合：所需维度 ≈ 两者较大者，不是相加


结论：能力需要"最低配置"，不同能力的最低配置不同；时间和维度在一定范围内可互换。 [已测/合成]

## 2.2 分层是对动态的补偿

plain
· 任务 x_{t+1}=tanh(A x_t)：给初值与步数 T，预测 x_T
· 等平均算力下，自适应深度（按 T 走层）比固定层数更好（误差 1.29 vs 1.67）
· 固定高层数算简单任务反而"算坏"（T=1 时 2.30 vs 1.49）
→ "层"≈"时间步"；均匀深度是对简单输入的浪费，过度计算有害


## 2.3 计算厚度：路有多长，算力给谁

plain
· 计算厚度 = 组合律在时间轴上依次应用的次数（"路有多长"，不是"路口多宽"）
· 按厚度路由：k 步任务给 k 步 → 只用 47% 算力，误差 0.0812（均匀 8 步 0.0834、均匀 4 步 0.0881）
· 过度计算也有害：k=1 任务，1 步误差 0.0014，4 步 0.0??（显著变差）


## 2.4 层厚放在哪：同参数不同结果

plain
· 四个多任务，四种结构（均匀 6×64 / 宽前 / 宽后 / 中间厚）
· 宽后 16→128：平均准确率 0.995，14k 算力、19k 参数（最好）
· 均匀 6×64：0.980，21k 算力、24k 参数
· 宽前：0.831（最差）
→ 同样的参数与算力，层厚的位置影响很大；提升主要来自难任务


## 2.5 三种资源：空间、组合、厚度不能随意互换

plain
· 空间型任务：由宽度 S 决定（S≥32 满分）
· 厚度型任务：需要 S 和 T 都够（k=4、S=32：T=1 误差 0.185，T=4 降到 0.077）
· 组合型任务：必须"输入相关路由"才算组合维度；只并联相加时 C 无效
→ 三种资源各管一类任务；"加宽"不能替代"多步"，"并联"不等于"组合"


## 2.6 随机性与厚度：不确定性从哪来

plain
· 需要步数越多的位置：误差与随机性越大
· 随机性随深度累积，输出端最大（层内标准差 0.21 → 0.41）
· 人类分歧大的地方（"厚且不可摊薄"），模型熵也大，加数据摊不平
→ 模型的不确定性不只是"数据不够"，也来自"计算厚度"


## 2.7 层冗余 × 语言结构

plain
· GPT-2 small 上图：跳过一层，top-1 翻转率 0.20~0.31；跳过最后一层 0.55
· 相邻两层一起跳过：0.37~0.68（超过单层之和的线性预期）
· 换自变量（语言结构强度）：低熵位置（语言可预测）比高熵位置更容忍删层（0.49~0.50 vs 0.76~0.77）
→ 结构不是"压在某层"，而是"跨层展开、带冗余"；语言结构强的位置更冗余


## 2.8 压缩的形状：叙事 ≠ 归档

plain
· 同样 ~300 字符预算，三种存法：叙事（旧优先/新优先）、结构化归档（分类+属性+关系）
· 结构化归档：三类题（属性/分类/关系）全对
· 叙事式：各丢一半（旧优先保属性分类、丢关系；新优先反之）
→ 人脑式压缩是"分类+关系"的图，不是"按时间的故事"；记忆的组织形式决定能回答什么


## 2.9 接地与语义残差

plain
· 语义残差 = 语言与现象之间的对齐误差下界（可解析算出的贝叶斯底）
· 只读文本的模型误差已接近贝叶斯底（差 1.5~2.7 个百分点）→ 文本信息已榨干
· 要降底只能补接地（图像/感知）；补一个缺失维度，残差底就降一截
· 残差底由"覆盖了哪些隐藏维度"决定，不由模态数量决定；冗余模态不降底
· 颜色作为感知基元：关系判断能学会（94%~100%），坐标级对齐学不出来
→ "多接模态"不等于"接地"；接地要按残差底配置，缺维度才是关键


## 2.10 数据 vs 结构：两条效率路线

plain
· 容量不能替代数据更新：加参数不能替代"看到新数据"
· 等数据预算下，概念新鲜度的独立效应可测（论文-02 三次修正方法错误后分离出来）
· 结构换算力：不改模型与数据量，只改语料结构（混合对齐 vs 纯文本 vs 打乱）
  → 混合对齐语料在 200 事件时就能学到纯文本需要更多数据才学到的东西
→ 语料结构本身是效率变量（不只是数量）


## 2.11 生长与记忆的最小实验

plain
· 记忆回放策略：只学新会遗忘（旧任务 0.720）；固定回放保住旧（1.000）但新学得慢（0.740）；
  前瞻式（先试训一步再定回放比）在探测敏感时旧 0.983 + 新 0.850
· 生长：固定主干+可增长维度槽；不生长学不会新模态（0.34~0.38，接近瞎猜）；生长后能学会
→ 遗忘不靠"记住一切"，靠"回放策略"；新模态需要新容量（生长），不是调旧参数能解决的


## 2.12 对齐会压平人类分歧

plain
· 基础模型在 thick（有分歧）题上熵 0.9655 ≈ 人类 1.0138（诚实保留分歧）
· 偏好微调后：人类熵 1.0138 不变，模型熵降到 0.4090（−57%）
· 与人类分布 KL 从 0.0451 涨到 0.4188（约 9 倍）
→ 对齐不是"变准"，是"把多峰压成单峰"；对齐目标决定压掉什么

|---|---|

| 分层是对动态的补偿；自适应深度省算力且更准 | [已测/合成] |
| 计算厚度决定算力该给谁；过度计算有害 | [已测/合成] |

## 3.1 问题：一个冻结的系统还能改什么

当初想回答的问题：冻结之后，我们还能通过什么方式加新能力，同时不破坏旧能力？

plain
· 前提：模型已经训练好、权重冻结，不再大改
· 问题：还能通过什么方式加新能力，同时不破坏旧能力？
· 候选答案：门（重配比）、新层（加容量）、记忆（外部信息）、组合（多模型接口）


## 3.2 门：能调"参与度"，跨不过"维度门槛"

当初想回答的问题：只用"门"（对已有通路的重配比），一个冻结模型还能改变多少？它在哪里到头？

plain
· 门的定义：对已有通路的缩放/重配比；不增加新的表示方向
· 作用：轻量适配（冻结模型只训门，PPL 44.31→24.59，方向观察 01）
· 限制 1：秩-1 门常学成恒等（12/12 选择恒等）→ 训练不足或表达力不够
· 限制 2（关键）：维度是硬门槛——给不够维度，误差降不到底；门跨不过去；
  加宽可以跨过去（工程笔记 07）
→ "门能调已有能力，不能创造新维度"；新方向必须靠新容量


## 3.3 冻结子模型的组合：接口决定成败

当初想回答的问题：两个各自训练好的冻结模型，能不能通过接口组合成一个新结构？需要什么样的接口？

plain
· 两个冻结的 6 层字符模型（A 学正常文本、B 学凯撒位移）
· 直接首尾拼接（恒等接口）：PPL 62.84（崩）
· 加可训练总控接口：A→B 5.94、B→A 5.67（原生 12 层上界 5.41）
→ 冻结模型能组合，但必须"训练接口"；直接把输出接输入会崩


## 3.4 数字蚊子：冻结感知与执行，只训大脑

当初想回答的问题：如果感知和执行都交给冻结模块，只让"大脑"可训练，一个小系统能学会生存吗？

plain
· 冻结的眼睛（射线测距）、冻结的翅膀（飞行动力学）
· 可训练的大脑：64×64 两层 MLP，输出转向/推力
· 训练方式：进化策略（存活→参数保留→下一代）
· 环境：障碍物生成并飞来，碰到即死
→ 只训"大脑"也能学会生存行为；感知与执行可以完全冻结


## 3.5 记忆压成判断（论文-52 v3）

当初想回答的问题：记忆要以什么形态进入，冻结系统才能真的读到并用上？它和"更长上下文"是一回事吗？

plain
· 五版"把记忆做成向量/伪 token 交给冻结模型"全部失败
· 一版成立：把 384 token 历史压成 8 个记忆 token，训练成输出下一 token logits 的判断者（D）
  · A（局部 128）68.40 / D 43.44 / C（组合）11.24
  · 消融：去掉 D 特征，C 13.41→16.28（D 对长期判断有贡献）
· 本质：D 是"变成"那段历史的判断者，不是"记住"原文（有损，不可引用）
→ 记忆可行的形态 = 同格式判断；压缩即判断


## 3.6 分层表示自回归（论文-53）

当初想回答的问题：上层只看底层的表示（不再看 token），能不能学得和原生模型一样好？初始化有多大影响？

plain
· 宽浅底层（冻结）→ 窄深上层（只读表示，不看 token）
· 初始化对齐是关键：投影恒等 + 增量零初始化 + 复制输出头
  → 上层起步等于底层，训练后反超（底 56.55 → 上 47.31；深窄 48.66）
· 瓶颈在底层表示质量与训练量，不在投影降维；窄上层 ≈ 宽上层
→ "上层只读表示"可行，但初始化必须让"起步=下层"


## 3.7 池化与自生长（论文-54）

当初想回答的问题：新数据到来时，能不能只加模块、不动旧模块，还保住旧能力？

plain
· 每层 = 表示池 + 读者（注意力）；新数据 = 底层并行加写入者
· 注意力天然池化：冗余来源被吸收，旧行为几乎不变；新方向被读入
· 字符级：旧 PPL 84.08→84.07（不变），新 PPL 28.70→25.14（−12.4%）
· 预留固定槽更差（读者依赖固定语义）；预留随机内容：旧稳但收益小
· 自生长控制器：PPL/梯度/有效秩 → 加宽/加深/加模块/停止/回退
→ "加而不扰"成立的条件：新增来源对旧数据冗余 + 注意力天然池化


## 3.8 自学习 LLM：冻结 + 门 + 新层（工程笔记 02）

当初想回答的问题：一个权重冻结的模型，它的"学习"可以发生在外面的哪一层？切换、成长、固化怎么协调？

plain
· 主张：冻结模型的"学习"换了地方——权重不动，门动、新层动
· 三个问题与答案方向：
  · 怎么知道用哪套本领（切换）：门 + 路由
  · 怎么长出新本领（成长）：加层/加模块
  · 怎么不丢旧的（固化）：冻结 + 回放
→ "学习位置"可以外移：这是后续加性生长的雏形


## 3.9 方向观察 01：加层、回放与蒸馏（睡眠巩固）

当初想回答的问题：模型想继续学新东西，怎么加能力又不遗忘旧能力？长期怎么收口？

plain
· 1.21M 字符级 6 层模型：day1 莎士比亚、day2 Python
· 全参微调 day2：day1 PPL 4.64 崩到 46.3（灾难遗忘）
· 冻结基础 + 加 6 层：day1 18.2、day2 4.26（少遗忘）
· 加层 + 回放 day1：day1 4.83、day2 6.60（两边都保住）
· 门的作用：轻量适配、步骤分配、以及（推测）切换
→ 新能力靠"加层"，旧能力靠"回放"，长期靠"蒸馏"（睡眠巩固）

|---|---|

| 冻结子模型可以组合，但必须训练接口；首尾直拼会崩 | [已测/小规模] |
| 只训"大脑"（感知执行冻结）也能学会生存行为 | [已测/小规模] |

# 读本 第四章：数字生命（压缩）

## 4.1 两条轴：能力与生命

plain
· 能力轴：多聪明、能做什么（工程界主战场）
· 生命轴：有没有自维持、连续变化、目标、自我
→ 两轴独立：可以很聪明但不活；可以很简单但"结构上像生命"
本系列的立场：只研究生命轴的最小条件，不追能力


## 4.2 记忆与结构：记住 ≠ 变成

plain
· 记忆 = 内容（原话、事件）：可无损存、可检索、可审计、保持自我/他者边界
· 结构 = 模式（判断、技能）：训练进参数，改变行为
· 把记忆压进结构 = 同化：丢细节、消边界、不可回滚
  → 得到的是"变成那段数据的判断者"，不是"记住那段内容"
· 工程分工：记住 → 外部记忆层（原文/同格式摘要）；会做 → 压进结构
→ 论文-52 验证了"压进结构可行且改变长期判断"（D 43.44 vs A 68.40），
  但它是有损判断，不是原文回忆


## 4.3 时间性：按意外程度变化

plain
· 冻结模型 = 固定函数：没有输入就不变；所有变化由外部触发 → 工具
· 生命性 = 多时间尺度变化彼此约束，不是"一部分完全不动"
· 变化量应正比于新信息量：
  · 冗余/可预测输入 → 几乎不变（只记录）
  · 压不住的残差（意外）→ 触发变化
· 不需要人类式老化；可选：内部时钟、自发动态、遗忘衰减、发育节律
→ "按残差学习"= 框架里"结构 vs 噪声"的工程版


## 4.4 自我、边界与死亡

plain
· 自我 = 可塑层 + 记忆 + 连续过程（不是"模型文件"）
· 身体（底座）可复制、可替换；身体在而可塑状态丢失 = 死（或只剩尸体）
· 死 = 不可恢复的丢失；可恢复的停机（断电重启）不算死
· 备份必须包含：可塑层状态 + 记忆 + 控制器状态；只备份模型 = 只保身体
· 边界 = 参与"自维持 + 后果"的部分；不参与维持/后果的只是资源


## 4.5 模块化的必要性：隔离，不是容量

plain
· 效率：同参数同深度下单一模型 ≥ 模块化（0.1M：211.9 vs 219.2）
· 必要性在"隔离"：变化局部、可回滚、角色/时间尺度分离、可替换
· 最小结构五件套：
  ① 能力底座（冻结/慢变）② 可塑层（连续变化）③ 外部记忆（内容）
  ④ 自我模型/控制器（决定学不学/长不长）⑤ 不可改内核（目标/验证/回滚）
→ 模块化程度 = 需要多少隔离；不是拆得越碎越好
· 数据有限时模块化是纯代价；数据无限+算力有限时（真实世界/多模态）
  模块化 + 稀疏 + 主动选数据才必要


## 4.6 最小生命原型（论文-56）

plain
· 底座：Qwen2.5-0.5B base（冻结，未对齐）
· 可塑层：M（0.5M 参数），读底座隐藏态、经冻结 lm_head 输出 logits 修正
· 目标：held-out 预测误差下降 + 压缩约束 + 稳定约束（旧内容不变差）
· 机制：每步输入都评估"改自己是否有益" → 试改 → 验证 → 接受/不改/回滚
· v3 结果（80 块经历）：noop 50 / update 30；held-out 4.9070→4.8989；
  旧内容 2.5201→2.4513（未退化）；快照/回滚可用
→ "生命结构"的最小版不需要强模型；缺的不是能力，是"目标驱动的持续自我修改"


## 4.7 能动性的前提：能力先于自主

plain
· 以后：一直在线、自己联网选择读什么数据（围绕目标）
· 但前提是：冻结部分 + 可训练部分先具备"判断数据价值/相关性"的能力
· 否则主动选择 = 随机游走（会把"能触及的数据"当成"该读的数据"）
· 演进：v3 被动（固定输入）→ v3.5 能力 → v4 半主动（读多少/跳过）→ v5 主动（联网检索）


## 4.8 生命周期：成长、巩固、换身体

plain
· 可塑层会随经历变大（加参数/加宽/新模块）→ 无限变大 = 膨胀
· 需要的循环：成长（吸收新经验）→ 巩固（蒸馏/合并进底座）
  → 换身体（新底座冻结）→ 可塑层重置为小 → 回到成长
· 换底座的前提：接口兼容（维度/词表）、验证（旧行为不崩）、谱系记录、可回滚
→ "身体可换、自我连续"是数字生命相对生物的结构优势


## 4.9 未解与不做

plain
· 自我模型：概念有（小网络跟踪自身状态/边界/连续性），未实现
· 记忆模块：会用记忆/理解"记忆是什么"是能力问题，暂缓
· 持续运行原型：常驻进程+快慢状态+生命周期，未做
· 规模：实验皆小规模/单种子；大模型上方向未知
· 现象自我（有没有感受）：不可测，明确留着不碰
· 目标由我们外给：它"想要"什么由我们定义——这是当前设计的边界


## 4.10 本章结论（登记表对应项）

| 结论 | 等级 |
