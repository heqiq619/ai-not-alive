# Translation Glossary (English) — Digital Life Series

Use these terms consistently in every English translation.

## Core terms
- 数字生命 = digital life
- 生命 = life；p生命 = p-life；R生命 = R-life
- 宇宙 = universe；宇宙函数 = universe function (F: S → S)
- 可函数化 = functionizable；可函数化的部分 = the functionizable part (P)
- 不可函数化 = non-functionizable；不可函数化的部分 = the non-functionizable part (R)
- 函数 = function；函数类 / 一族函数 = function family / a family of functions / function class
- 动态函数类 = dynamic function class
- 定义域 = domain；值域 = codomain；中面 = middle surface (of a thickened surface)
- 观察者 = observer；相对 R = relative R；绝对 R = absolute R
- 被保住 = preserved (by the universe)；维持 = maintenance；可维持 = maintainable；可维持集合 = maintainable set
- 自指 = self-reference；自指更新 = self-referential update
- 会变化 = changing；一族 = a family (not a single point)
- 解压 = decompression；再解压 = re-decompression；压缩 = compression
- 残差 = residual；误差下限 = error floor / lower bound on error
- 厚度 = thickness；变厚 = thickening；薄 = thin
- 摊平 / 摊薄 = flatten / flatten away；不可摊薄 = non-flattenable
- 升维 = raising dimension / adding dimensions；降维 = dimensional reduction / dimensionality decrease
- 分层 = layering；层 = layer；深度 = depth；隐层 / 隐藏层 = hidden layer
- 环境 = environment；局部解压 = local decompression；分层的 = layered / hierarchical
- 语义 = semantics；语义残差 = semantic residual；接地 = grounding
- 贝叶斯底 / 贝叶斯误差底 = Bayes floor / Bayes error floor
- 歧义 = ambiguity；受控歧义 = controlled ambiguity
- 涌现 = emergence
- 熵 = entropy；热寂 = heat death；时间尺度 = timescale
- 闭环 = closed loop；记忆库 / 回放 = memory buffer / replay；控制器 = controller
- 维度 = dimension；表示维度 = representational dimension
- 生长 = growth；休眠 = dormant；复活 = reactivation
- 自适应深度 = adaptive depth；早退 = early exit；条件计算 = conditional computation
- 人类分歧 = human disagreement；方差 = variance；标准差 = standard deviation；熵底 = entropy floor

## Series labels
- 第零篇 = Paper 0 (Introduction)
- 第一篇 = Paper 1 … 第十一篇 = Paper 11
- 实验篇 2 = Experiment Paper 2 … 实验篇 7 = Experiment Paper 7
- 理论笔记 2 = Theory Note 2
- 系列合集 = Series Compendium
- 导论 = Introduction

## Style rules
1. Full faithful translation: keep every heading, paragraph, number, table row, DOI, and label ([定义] → [definition], [推论] → [corollary/inference], [推测] → [speculation], [猜想] → [conjecture], [事实] → [fact], [画面] → [picture], [可测] → [measurable], [不声称] → [not claimed]).
2. No code blocks; no added content; no omissions.
3. Keep author line: "He Qi · with DeepSeek (AI)".
4. Header block of every English file must include: "English translation of the Chinese original. The Chinese text is authoritative: <Chinese DOI>" and "Series page: https://github.com/heqiq619/ai-not-alive".
5. Titles: translate naturally, keep meaning.
6. Numbers and experiment results: unchanged.
