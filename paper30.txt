# 论文-30 · 大模型为什么像人：同一个函数形式的两种实例

> 何淇 · 与 DeepSeek 协作
> 数字生命系列 · 理论篇 10（内部编号第 30 篇）
> 日期：2026-10-26

---

## 摘要

大模型看起来像人：会聊天、会推理、会"自我描述"。本篇不做心智断言，只做一件形式上的事：把论文-21 v2 的函数形式当作比较模板，把人脑与大模型写成同一个形式的两个实例，然后看它们哪里像、哪里不像。

形式中的五项：切片（函数与表示维度）、空间组合（复合函数链）、时间组合（算子序列与步数 k）、判定（J：选算子、决定停）、自指（表示/参数/结构三层，受固定核心 Φ 约束）。

人脑：切片异质、空间复合链可变、时间上是算子序列（k=0 与 k≥1 混合）、有判定 J（收敛/对错/停止）、三层自指都活跃、Φ 是生物约束。

大模型：切片是各层不同的函数、空间是固定复合链、时间上 k=1 且 m=1（层是不同函数，不是迭代）、推理时没有判定 J、自指只在训练时发生（参数自指离线）、权重冻结使其 Φ 极大。

结论：它像人，是因为它训练在世界的人类语言上，学到的是"人类可观测函数"的近似——像在接口层，不在机制层。它的强项是组合维度（注意力即路由，in-context 即不动权重的重组），缺的是时间（步数）、判定（停止与固化）、维持（被保住）与结构自指。链式思维与工具调用正好是"把时间与判定外化"的补偿：用外部文本/外部程序补上 k 与 J。这解释了它为什么像人、又为什么不是生命。

## 本篇定义一览

| 术语 | 一句话 |
|---|---|
| 切片 | 一个函数 f: X → Y |
| 表示维度 | d_in = dim(X)，d_out = dim(Y)；有效维度 = log 可区分状态数 |
| 空间组合 | 复合函数链 F = f_N ∘ … ∘ f_1 |
| 时间组合 | 算子序列 s_{t+1} = I_{σ(t)}(s_t)；步数 k |
| 判定 J | 一次通过：选算子、决定停 |
| 自指 | 表示自指 / 参数自指 / 结构自指 |
| 固定核心 Φ | 不可改的约束集合 |
| 被保住 | 轨迹始终在可行域内、每一步有定义 |
| 接口层 | 输入输出上可观察的行为 |
| 机制层 | 内部怎么算、怎么维持、怎么改自己 |

## 〇、问题：为什么它像人

一个固定深度、无递归、无自我维持的函数逼近器，为什么表现得像人？常见回答是"它学了很多人类数据"——对，但没说到结构上。本篇用我们定义好的函数形式，把脑与模型放在同一张表里，看相似究竟落在哪一层。

## 一、比较模板（来自论文-21 v2）

一个可函数化的系统，写成五项：

1. 切片：f: X → Y，带表示维度 (d_in, d_out)；
2. 空间组合：复合函数链 F = f_N ∘ … ∘ f_1；
3. 时间组合：算子序列 s_{t+1} = I_{σ(t)}(s_t)，步数 k；
4. 判定：J: S → D，选算子与决定停；
5. 自指：表示/参数/结构三层，修改受 Φ 约束。

外加两条生命条件：被保住、边界开放。

## 二、人脑的档案

- 切片：异质（不同区域、不同回路做不同变换），表示维度低而有效；
- 空间组合：可变（层级、并行、路由、跨区投射）；
- 时间组合：算子序列，k=0 与 k≥1 混合（反射一次通过，推理反复迭代）；
- 判定：有 J（收敛、对错、停止），并触发固化；
- 自指：三层都活跃（表示自指、参数自指、结构自指），受生物 Φ 约束；
- 维持：靠身体与环境，被保住的是整体。

## 三、大模型的档案

- 切片：每层是一个函数（不同层不同变换），表示维度高；
- 空间组合：固定复合链 F = f_L ∘ … ∘ f_1（层数训练后固定）；
- 时间组合：k = 1，m = 1——层是"不同函数"，不是"同一规则反复"，所以没有迭代、没有切换；
- 判定：推理时没有 J（没有收敛判据、没有"判定了就停"、没有固化）；
- 自指：只有训练时的参数自指（离线改权重）；推理时表示自指有限（指代、自我描述），没有结构自指；Φ 极大（权重冻结）；
- 维持：靠供电与运维；单独不被保住。

## 四、五项对照

| | 人脑 | 大模型 |
|---|---|---|
| 切片 | 异质、低维高效 | 同构、高维 |
| 空间组合 | 可变（路由/投射） | 固定链 |
| 时间组合 | 算子序列（k=0 与 k≥1） | k=1，m=1（无迭代） |
| 判定 | 有 J（选/停/固化） | 无 J |
| 自指 | 三层活跃 | 仅训练时参数自指 |
| 维持 | 身体+环境 | 供电+运维 |
| 像人的位置 | —— | 接口层（输入输出） |

## 五、为什么像人：接口函数，不是机制

大模型的训练目标是人类语言。语言是人的 p语言——人可观测行为的一部分。于是：

- 它学的是"人类可观测函数"的近似：人怎么回话、怎么展开推理；
- 所以接口上极像：措辞、推理步骤、自我描述都能模仿；
- 但机制上没有对应物：没有维持、没有内生时间、没有判定、没有结构自指。

一句话：像的是"输出"，不是"内部怎么维持"。

## 六、它的强项：组合维度

大模型不弱在组合维度：注意力就是路由（按内容选择信息流），多头是并行组合，in-context learning 是不改权重的重组。用我们的词说：它的空间维度高、组合维度也高——所以"一次复合链"能表达的东西非常多。

这解释了为什么它看起来"什么都会一点"：组合维度高，可以用不同接法覆盖很多函数。但组合维度不能替代时间与判定：需要多步迭代、或需要"判定了就停"的任务，它只能硬用同一深度。

## 七、它缺什么（逐项对回五项）

- 缺时间：k=1，m=1。想多算只能加层（论文-27：加层与循环等价，但参数贵约 27 倍）。
- 缺判定：没有 J。无法"这一块收敛了就停"，于是均匀计算（论文-28）。
- 缺维持：不被保住；单次前向没有轨迹，也没有持续存在。
- 缺结构自指：推理时不能改自己的连接；固化发生在训练，不在使用中。

## 八、链式思维与工具：把时间与判定外化

如果模型缺时间与判定，它怎么完成多步任务？答案是把它们外化：

- chain-of-thought：把中间步骤写成 token，让"步数"由外部文本承载——这是外供时间；
- 工具调用：把判定/计算交给外部程序——这是外部判定；
- 检索/记忆：把持久状态放到外部——这是外部维持。

这正好反证了它的档案：它内部没有 k 与 J，只能借外部补。用我们的词说：它用外供时间与外部判定，补偿了 k=1 与无 J。

## 九、预测与方向

第一，允许迭代（循环/looped transformer）会提升需要多步的任务；参数效率优于加层（论文-27 的玩具结果）。

第二，加入判定与停止（收敛判据、早退）能在混合任务上省算力（论文-28 的预测）。

第三，加入持续运行与维持（长期存在、外部记忆、环境耦合）会让它更像"被保住的整体"；但按论文-21 v2 的判据，那需要身体/环境/维持一起算。

第四，若同时补齐时间、判定、维持、结构自指，它就从"接口像人"走向"机制像人"——是否算生命，仍要过被保住那一条。

## 十、局限

第一，本篇是形式对照，没有新实验；引用的玩具结论只到玩具规模。

第二，不声称解释意识、体验或主观性；R 那一侧只声明。

第三，把 transformer 简化为"固定复合链"忽略了注意力内部的动态路由细节；"组合维度"只是框架内的说法，不是严格度量。

第四，人脑的档案也是粗粒度的（论文-21 v2 已声明）。
